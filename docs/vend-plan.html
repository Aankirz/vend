TL;DR in 60 seconds

If you read nothing else, read these four cards.

😩 The problem

Developers publish free tools for AI agents. Agents hammer them, the author pays the hosting bill and earns $0. Charging is hard: agents can't fill sign-up forms or checkout pages, and setting up servers, billing and security takes weeks.

✨ The product

Vend's AI agent wraps the tool, tests it in a sealed CreateOS computer, fixes its own bugs and publishes it behind a Stripe "pay first" toll gate. Any agent can now pay per call.

🔒 The secret

In agent commerce, trust is the product, not payments. Vend gives three guarantees: verified before going live, sealed while running, and no charge if the call fails.

💰 Why sponsors love it

Every Vend seller becomes a new Stripe merchant and a new always-on CreateOS workload. We bring both companies customers instead of reselling their product.

How we got here

The idea went through four versions. Each version was attacked, and only the parts that survived were kept.

STEP 0 · RESEARCH

Read the hackathon page, Luma, Discord and the 30 ideas

We scored every idea: 3 × value to sponsors + 2 × demo appeal + 1 × ease (max 30). Then we found the actual judging rules in Discord: sponsor-tool usage, the agent writing, running and fixing its own code, a real user, clear execution, creativity.

VERSION 1 · RunMeter · killed

"Pay-per-run code runner": agents pay to run code in a sandbox

Top score (28/30), but it failed self-questioning. The user was vague ("any agent"). It was CreateOS's own idea #22, so nothing creative. And it was fatal: it resold CreateOS sandboxes back to CreateOS. "why wouldn't the agent just use CreateOS directly?"

VERSION 2 · Vend v1

"Turn any function into a paid API for agents"

Insight: nobody pays for raw compute, they pay for what the code does. So we sell people's useful code, not computers. That made it a two-sided product, sellers and buyers, and it grows the sponsors instead of competing with them.

VERSION 3 · Vend v2 · product books + competition check

"Pay only if it works", with a narrow first user group

The competition check showed Stripe already makes the paywall easy, so a paywall can't be our value. Ten product books pushed us to a narrow first user group (open-source agent-tool authors), an answer to the empty-marketplace problem, and a unique hook: automatic refunds when a call fails.

VERSION 4 · Vend v3 · sponsor docs + YC battle-test (current)

"Make your agent tool pay for itself"

Sponsor docs revealed three gifts: Stripe's Link agent wallet (real off-the-shelf agents can pay), Connect (automatic 90/10 seller split) and Refunds working with agent payments. The YC lens reframed the pain from "side income" (nice-to-have) to "your free tool is costing you money" (urgent).

Jargon decoder

Sandbox / micro-VM

A tiny throwaway computer in the cloud. Like a sealed glass room: whatever happens inside stays inside.

HTTP 402

Websites reply with codes. 404 = "not found". 402 = "payment required". MPP makes 402 actually work.

MPP

Machine Payments Protocol. Stripe's 2026 standard that lets a program pay another program automatically.

Ingress / Egress

Ingress = who can come in (public URL). Egress = where code may go out (we allow almost nothing).

Stripe Connect

Stripe's marketplace system: money goes to the seller, and the platform keeps a cut automatically.

Test mode

Stripe's practice mode. Payments look real, but no money moves. Everything in the demo uses it.

How well the product is thought out

Who it's for, what job it does, and why it beats the alternatives.

👤 First users (beachhead)

Authors of open-source agent tools and MCP servers on GitHub. They exist today, in the thousands, and earn $0 while their tools get heavy agent traffic.

🔥 Urgent pain

"My free tool is costing me money." Hosting bills grow with agent usage, so authors shut tools down or stop maintaining them.

🛠 Job to be done

Seller: "Make my tool pay for itself without becoming a billing engineer." Buyer agent: "Get a trustworthy result from a stranger without risk."

📏 North-star metric

Time to first paid call. DIY takes weeks. Vend: under 2 minutes, shown live with a timer.

🎯

Positioning line: "Stripe made charging agents a one-prompt job. Vend does the rest: hosting, safety, proof."

The three trust guarantees (our "secret")

✅ Verified

Tests pass in a sandbox before the tool goes live. The agent fixed its own bugs to get there.

🔒 Sealed

Tool runs in its own micro-VM with the network locked. Malicious input can't leak anything.

↩ No result, no charge

If the call fails, the gateway refunds automatically. None of the 100+ services on MPP today does this.

Business model

10% of every payment, collected through Stripe Connect. One $0.50 call = $0.45 to the seller, $0.05 to Vend. This is built into the MVP, not just a slide (falls back to a ledger if Connect isn't available on an Indian account).

Round 2: the facts that changed the plan

threat Stripe already does paywalls

Stripe offers a one-prompt way to charge agents and a "monetize your MCP server" guide. Paywall alone = no value, so we moved the value to hosting, safety and proof.

signal Demand is real

100+ services launched on MPP on day one, and a public GitHub request on Stripe's own repo asks for pay-per-call for agents (stripe/ai #347).

gift Link agent wallet

Off-the-shelf agents can pay in test mode, so the buyer in the demo is real.

limit Free plan = 1 sandbox

We need ~2, so the $10 Beginner plan is approved. Some agent payment features have country limits; that gets tested first.

Round 3: the YC application

What are you making?

Vend turns any agent tool into a paid service in 90 seconds. An AI packages, tests and fixes it in a sealed computer and publishes it. Any agent pays per call with Stripe, and only if it works.

Who desperately needs it?

Authors of free agent tools paying hosting bills for heavy agent traffic, with no way to charge customers who can't use checkout pages.

Why now?

2026: Stripe MPP launched (agents can pay), Link agent wallet (agents have wallets), cheap instant micro-VMs (strangers' code can run safely). None existed 12 months ago.

What do you know that others don't?

Payments are solved. Trust between strangers' code isn't. Agents will buy from strangers only if the code is verified, sealed and refund-backed.
