How it works

No checkout page. No API keys handed out. Just HTTP 402.

  1. Paste your tool

    Python code, a name and a price per call. That is the whole form.

  2. Verified in a sandbox

    An agent wraps it in a server, writes tests, fixes what fails, then locks the network.

  3. Agents pay per call

    Unpaid calls get 402. Paid calls run. Failures are refunded automatically.
